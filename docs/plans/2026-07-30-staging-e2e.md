# Staging End-to-End Acceptance Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 建立并运行覆盖消费者交易、商家履约和商品管理的预发布 Playwright 全链路测试，修复首轮缺陷并纳入回归。

**Architecture:** 在 `apps/e2e` 建立与两个 Vue 工程解耦的黑盒测试工程，通过可配置域名访问预发布环境。公开冒烟与完整串行交易分开；商家凭据只从环境变量读取，失败证据自动脱敏并保存。

**Tech Stack:** Playwright Test、Node.js 22、GitHub Actions、Vue 3、Spring Boot、MySQL 8

---

### Task 1: 建立独立 Playwright 工程

**Files:**
- Create: `apps/e2e/package.json`
- Create: `apps/e2e/package-lock.json`
- Create: `apps/e2e/playwright.config.js`
- Create: `apps/e2e/.env.example`
- Modify: `.gitignore`

**Step 1:** 编写配置校验测试，要求域名为 HTTPS，完整验收缺少商家凭据时明确失败。

**Step 2:** 运行测试并确认因工程尚未配置而失败。

**Step 3:** 添加 Playwright 配置、脚本、失败截图、视频、trace 与 HTML 报告。

**Step 4:** 安装依赖并运行配置测试，预期通过。

**Step 5:** 提交独立测试工程。
