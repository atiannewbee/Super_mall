## 设计复核

- 商品规格使用规范化属性和值表，满足前端现有颜色、容量、内存、尺寸、表带、支架和轴体组合。
- 实时库存与库存流水分离，并预留乐观锁版本字段。
- 订单保存商品、SKU、价格和地址快照，主数据更新不会污染历史。
- 订单、支付、履约和售后状态分离，状态历史支持前端时间线与未来 Agent 审计。
- 支付单号、渠道交易号、订单号、SKU 编码和商品 slug 具有唯一约束。
- 高频查询具有用户/状态/时间、分类/状态/排序等组合索引。
- 当前没有为未来多商户强行加入空字段；通过模块和迁移边界扩展。

## 安全复核

- 跟踪配置不再包含数据库明文密码，密码由环境变量或被忽略的本地文件提供。
- Flyway clean 已禁用。
- 生产环境仍需创建专用低权限 MySQL 用户，禁止使用 root。
- 用户密码只允许保存强哈希，当前数据库不保存明文密码。
- AI 客服和运营 Agent 不应直接持有数据库写权限，只能调用带鉴权与审计的应用接口。
